# Input data

The shared notebook references an image stored at a Google Colab path, but the
image itself was not included. You can use an image that you have permission
to use by placing it in this folder or providing its path directly to the task
script.

For example:

```bash
python tasks/task_01_orb_feature_matching.py data/my-image.jpg
```

Image files in this directory are intentionally ignored by Git so personal or
copyright-restricted images are not uploaded accidentally.
